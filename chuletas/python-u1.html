★f-strings meter variables en un texto

Una f delante de las comillas y la variable entre {llaves}. :.2f deja dos decimales.

precio = 10 / 3
print(f"Precio: {precio:.2f} euros")
print(f"Doble: {precio * 2:.1f}")
Precio: 3.33 euros
Doble: 6.7
Sin la f, sale el texto de las llaves tal cual: Precio: {precio:.2f} euros

4Decisiones if · elif · else

Dos puntos : al final y sangría (4 espacios) debajo. El elif y el else son opcionales. El else nunca lleva condición.

if condicion:
    # si se cumple
elif otra_condicion:
    # si no, y se cumple esta
else:
    # si no se cumple ninguna

★Gana la primera que se cumple

Ordena de más exigente a menos. Lo que va sin sangría está fuera del if y se ejecuta siempre.

nota = 9.5
if nota >= 9:
    print("Sobresaliente")
elif nota >= 5:
    print("Aprobado")
print("Fin")
Sobresaliente
Fin
Las mayúsculas cuentan: "Si" == "si" es False. Usa .lower().

10Funciones def · parámetros · return

Definir no ejecuta nada: hay que llamarla. Los datos entran por los parámetros, en orden; el resultado sale con return.

def media(a, b):
    return (a + b) / 2

m = media(6, 9)
print(m)
7.5
print solo enseña; return entrega. Una función sin return devuelve None. Lo que se crea dentro de una función no existe fuera.
